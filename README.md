# Sales Data Analysis Project

## About the Project
Sales Data Analysis is a Python-based project developed to analyze, clean, and visualize sales data using Pandas and Matplotlib.

The project helps understand product-wise sales performance through data analysis and graphical visualization.

## Features
- Load sales data from CSV files.
- Display the first five records.
- Check dataset information and shape.
- Identify missing values and duplicate records.
- Clean missing and duplicate data.
- Calculate total sales.
- Generate Bar Chart.
- Generate Line Chart.
- Generate Pie Chart.
- Save cleaned data and chart images.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV
- Visual Studio Code

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the following command:

```bash
python main.py
```

## Visualizations

The project generates three types of charts:

1. Bar Chart – Product-wise sales comparison.
2. Line Chart – Product-wise sales visualization.
3. Pie Chart – Product-wise sales distribution.

## Conclusion

This project provides practical experience in Python programming, data cleaning, data analysis, and visualization. It helps transform raw sales data into meaningful information.
